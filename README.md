# JavaHasiok

JavaHasiok is a collection of small Java console programs created for programming practice. The project contains exercises about basic syntax, input from the keyboard, conditional statements, loops, arrays, strings, text files, matrices, random numbers, and simple object-oriented programming.

Most source files are placed in the `School` folder and can be run independently from IntelliJ IDEA or from the terminal.

## Project structure

```text
JavaHasiok/
|-- README.md
`-- School/
    |-- *.java              # Java source files
    |-- *.txt               # input/output text files used by file exercises
    |-- School.iml          # IntelliJ IDEA module file
    |-- .idea/              # IntelliJ project settings
    `-- out/                # compiled classes generated by IntelliJ
```

## Main topics

- Console input with `Scanner`
- Arithmetic calculations and simple calculators
- `if`, `switch`, loops, and menus
- Random number generation
- Arrays and matrix operations
- String processing
- Reading and writing text files
- Basic classes, objects, inheritance, and abstraction

## How to run

### IntelliJ IDEA

1. Open the `JavaHasiok/School` folder as a project.
2. Choose one Java file with a `main` method.
3. Run the selected class.

### Terminal

From the `School` directory:

```bash
javac FileName.java
java FileName
```

Example:

```bash
cd School
javac Zad2_Kacper_Krakowski.java
java Zad2_Kacper_Krakowski
```

Some programs use text files, so run them from the `School` directory to make sure files such as `domy.txt`, `tekst.txt`, or `liczby.txt` are found correctly.

## Notes

- The `out/` directory contains compiled `.class` files generated by IntelliJ IDEA. It is not source code.
- Most files are independent exercises and do not form one single application.
- `KlasyObiekty.java` appears to be a demonstration file for object-oriented classes, but it may need to be wrapped in a class before compiling directly.
- `Zadanie_11.java` declares a package, so it should be compiled/run using the matching package directory structure or configured correctly in IntelliJ IDEA.
